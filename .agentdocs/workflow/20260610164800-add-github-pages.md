# 新增 GitHub Pages 可视化页面

## 背景与目标
- 主题仓库需要一个可视化浏览和筛选主题的入口
- 支持按 scene 和 tag 归类筛选，支持关键字搜索
- 以卡片布局展示主题，卡片预览区展示 examples/ 中的图片（多图水平滚动）
- 无图时展示主题色渐变氛围卡作为 fallback

## 约束与原则
- 纯静态站点，使用 docs/ 目录部署，无需构建工具
- 零依赖：原生 HTML/CSS/JS，不引入任何框架
- 数据索引通过 Node.js 脚本自动生成
