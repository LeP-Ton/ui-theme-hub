# 移动端界面专属规范

## 布局

### 应用外壳

```
┌──────────────────────┐
│ 状态栏（safe-area）   │
├──────────────────────┤
│ 导航栏（44px）        │
├──────────────────────┤
│                      │
│ 内容区域             │
│ （可滚动）           │
│                      │
├──────────────────────┤
│ 底部标签栏（50px）    │
├──────────────────────┤
│ 安全区（safe-area）   │
└──────────────────────┘
```

- 安全区：`env(safe-area-inset-top/bottom)`
- 导航栏高度：44px
- 标签栏高度：50px + 安全区

### 推荐技术栈

React + 移动端适配（viewport meta + rem/vw）

## 触控规范

| 项目 | 要求 |
|------|------|
| 最小点击区域 | 44x44px |
| 相邻可点击元素间距 | >= 8px |
| 滑动手势区域 | >= 20px |
| 长按触发时间 | 500ms |

## 手势交互

| 手势 | 操作 | 场景 |
|------|------|------|
| 下拉 | 刷新 | 列表顶部 |
| 左滑 | 删除/归档 | 列表项 |
| 右滑 | 标记/收藏 | 列表项 |
| 长按 | 上下文菜单 | 列表项、图片 |
| 双指缩放 | 放大查看 | 图片 |

## 视觉规范

- 基础字号：16px（避免浏览器自动缩放）
- 内边距：16px
- 卡片圆角：radius-lg（8-12px）
- 底部标签图标：24px + 文字 10-12px

## 性能规范

- 图片懒加载 + WebP 格式
- 列表虚拟滚动（长列表）
- 骨架屏替代白屏
- 避免大图/重动效
