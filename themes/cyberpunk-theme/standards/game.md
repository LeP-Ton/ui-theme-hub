# 游戏 UI 专属规范

## 布局

### 游戏 HUD 结构

```
┌──────────────────────────────────────────┐
│ 顶部状态栏（血条/蓝条/等级）             │
├──────────────────────────────────────────┤
│                                          │
│          游戏画面区域                     │
│                                          │
├──────────────────────────────────────────┤
│ 技能栏（底部居中）                       │
│ [技能1][技能2][技能3][技能4][技能5]      │
├──────────────────────────────────────────┤
│ 小地图（右下角）  │ 背包快捷（右下）     │
└──────────────────────────────────────────┘
```

### 推荐技术栈

React/Canvas + CSS（特殊布局，动效丰富）

## 视觉风格

- 暗色背景为主
- 边框发光效果（box-shadow glow）
- 品质色彩编码：普通=白，优秀=绿，稀有=蓝，史诗=紫，传说=橙
- 图标风格：写实或卡通，与游戏美术一致
- 字体：粗体、有力量感的字体

## 组件规范

### 技能栏

- 技能槽位：56x56px
- 间距：4px
- 冷却动画：扇形遮罩
- 快捷键标注：左上角小字

### 背包栏

- 网格尺寸：64x64px
- 间距：4px
- 品质边框色：按品质色彩编码
- 拖拽交互：拖动到装备槽或丢弃区

### 状态条

- 血条：红色渐变，12px 高
- 蓝条：蓝色渐变，8px 高
- 经验条：金色渐变，4px 高
- 低值警告：血量 < 25% 时闪烁

### 弹窗面板

- 半透明暗色遮罩
- 面板边框发光
- 关闭按钮在右上角
- Tab 切换不同子面板

## 交互规范

- 拖拽：背包物品拖拽
- 右键：上下文菜单
- 双击：快速使用/装备
- 悬浮提示：物品详情 Tooltip
- 快捷键：技能和背包快捷键

## 动效规范

- 冷却动画：扇形展开
- 伤害数字：上浮淡出
- 升级：光效爆发
- 装备：品质光效
- 动效可关闭（性能模式）

## 文字动画（PoemTextAnimator）

主题依赖 `poem` 文字动画库，用于游戏内逐字/逐行动画效果（剧情对话、技能名称、伤害数字、物品描述等）。

### 安装

```bash
# 从仓库克隆到项目 libs 目录
git clone https://github.com/LeP-Ton/poem.git src/libs/poem
```

```tsx
// 引入
import { createTextAnimator, splitTextToSpans } from '@/libs/poem/index.js';
import '@/libs/poem/index.css';
```

### 核心 API

**创建实例**：

```tsx
const animator = createTextAnimator('#dialog-container', {
  animationClass: 'one',    // 动画预设名（one ~ seven）
  charDelay: 0.05,          // 字符间延迟（秒），默认 0.05
  lineInterval: 1000,       // 逐行间隔（毫秒），默认 1000
});
```

**渲染方法**：

```tsx
// 渲染单行文字（逐字动画）
animator.render('勇敢的冒险者，欢迎来到黑暗大陆');

// 逐行渲染（剧情对话场景）
await animator.renderLines([
  '第一章：黑暗降临',
  '远方的地平线被血色染红',
  '你握紧了手中的利刃...',
]);

// 销毁实例
animator.destroy();
```

**工具函数**：

```tsx
// 将文本拆分为带延迟的 span 元素（用于自定义容器）
splitTextToSpans(targetElement, '技能已解锁', 0.05);
```

### 游戏场景使用规范

| 场景 | 推荐预设 | charDelay | 示例 |
|------|---------|-----------|------|
| 剧情对话 | `one` | 0.05 | NPC 对话逐字显示 |
| 技能名称 | `three` | 0.03 | 技能解锁时名称闪现 |
| 物品描述 | `two` | 0.04 | 物品详情逐字展示 |
| 标题/横幅 | `five` | 0.08 | 章节/场景标题 |

### 注意事项

- 动画实例使用完毕后需调用 `destroy()` 释放资源
- 性能模式下（`motion.enabled: false`）跳过文字动画，直接渲染完整文本
- `animationClasses` 数组可按行循环分配不同动画预设
- `animationResolver` 可自定义每行动画类名
