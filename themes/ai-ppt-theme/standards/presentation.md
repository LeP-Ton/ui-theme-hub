# 演讲演示稿专属规范

## 设计基调

暖橙（`#ff6a3d`）+ 天蓝（`#0076ff`）双色搭配，浅蓝渐变底（`#f4f8ff → #fff5ea`），
毛玻璃面板 + 浮动彩色光斑。整体偏「轻松、温暖、可亲近」，区别于纯科技风的冷峻，
适合团队内部分享、AI 主题演讲、轻量级技术布道。

## 布局

### 典型演讲稿布局

```
┌──────────────────────────────────────────┐
│ 顶部元信息栏（kicker + 标题 + 控制组）   │
├──────────────────────────────────────────┤
│                                          │
│  幻灯片舞台（毛玻璃面板，圆角 22px）     │
│  ┌────────────────────────────────────┐  │
│  │ 页签 · 页标题 · 正文 · 内容块      │  │
│  └────────────────────────────────────┘  │
├──────────────────────────────────────────┤
│ 底部进度栏（页码 · 进度条）              │
└──────────────────────────────────────────┘
```

- 顶部元信息栏可承载分享副标题（kicker）与翻页控制
- 舞台面板用 `backdrop-filter: blur(8px)` 叠加在光斑背景上
- 单页内容纵向排布：页签 → 大标题 → 正文 → 内容块（指标/双栏/列表）

## 视觉风格

- 字体：标题用 `Space Grotesk`，正文用 `Noto Sans SC`，标题加 `letter-spacing: 0.02em`
- 背景：浮动光斑用 radial-gradient + blur，三个光斑分别橙、蓝、黄，opacity≈0.58
- 面板：`rgba(255,255,255,0.8)` 半透明白 + `blur(8px)`，圆角 22px / 14px
- 卡片：`rgba(255,255,255,0.73)`，边框 `rgba(12,35,64,0.14)`
- 强调色：主按钮 / 进度值用橙渐变 `linear-gradient(120deg, #ff6a3d, #ff946e)`
- 辅助色：页签 / 链接 / 进度条用蓝 `#0076ff` 或蓝渐变
- 条幅（callout）：左边框 5px 橙 + 橙色半透明底，用于关键词强调

## 内容块类型

| 块 | 适用场景 | 结构要点 |
|----|----------|----------|
| metric-grid | 前言/总结页定位指标 | 3 栏，橙色大字 + 灰色说明 |
| dual-column | 问题/方法、痛点/方案对照 | 2 栏卡片 + 可选 callout |
| quad-grid | 四象限思维模式拆解 | 2×2 网格 |
| timeline | 阶段/技能演进 | 纵向列表 |
| phase-grid | 三阶段案例对比 | 3 栏卡片 |
| checklist | 观点清单 | 前置粗体标签 + 描述 |

## 交互规范

- 翻页：方向键 / 空格，切页时当前页滑入（translateX + scale）
- 切页动效：`transition: opacity 340ms ease, transform 340ms ease`
- 内容渐显（reveal）：进入视口 `translateY(12px) → 0`
- 进度条：底部宽度按 `当前页/总页数` 填充，蓝渐变
- 标题动画：切页时逐字拆分重播（依赖 poem 动画库，作用域限 `.slide-title`）
